# Chicken Gun: Version 0.5.0 (Myth / ARG)

Welcome to the repository dedicated to **Chicken Gun Version 0.5.0** — a popular fan-made urban legend, creepypasta, and ARG (Alternate Reality Game) created by the player community.

## About the Legend
According to the fan lore, version 0.5.0 is a lost test build (Indev) made on the Unity engine that existed between 2015 and 2019.
* **Found Footage:** Inspired by eerie archive videos styled with glitches and jumpscares.
* **Entities:** Features mysterious characters such as *Inscripter*, *X22*, and creepy versions of regular chickens.
* **Locations:** Includes dark versions of classic maps like *Old Dust_2* and *TownOfChalo*.
